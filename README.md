# Problem #12: Executive Decision Intelligence

## Overview
A strategic decision-intelligence engine that runs statistical sensitivity analysis linking hundreds of departmental operating KPIs against bottom-line financial performance (EBITDA & Net Profit), identifying true causal drivers from operational noise.

### Features
- **Correlation & Causal Ranking**: Isolates which metrics exhibit strong statistical coupling with quarterly profit.
- **Noise Filtering Engine**: Classifies KPIs into Primary Bottom-Line Drivers, Contributors, and Low-Leverage Noise.
- **Executive Automated Briefing**: Synthesizes cross-departmental findings into high-level C-suite takeaways.
- **Interactive Web Interface**: Live financial trajectory timelines and Pearson correlation ranking bar charts.

## Running the Application
```bash
python main.py
```
